# AGENTS.md

motion-studio produces brand animations. Each ships as one portable
`builds/<brand>-<slug>.html` that plays by itself and makes zero network
requests. Films are authored as HyperFrames HTML, validated in a real browser,
and built deterministically: the same sources always produce the same bytes.

This file is the whole contract. Read it before touching anything.

## Read this before you act

| Task | Read |
|---|---|
| Change a film | `work/<brand>/<slug>/film.json`, `beats.html`, `NOTES.md` |
| Start a film | this file, then `npm run new <brand> <slug> --duration=12` |
| Change a brand | `brands/<slug>/brand.ts`, `brands/pack.ts` |
| Understand a gate failure | the failing tool under `tools/` |
| Set up the repo | `README.md` |

Do not read `builds/*.html` or `node_modules/`. Built films are generated, up
to three megabytes on one line, and nothing in them is editable.

## Setup

```
npm ci
npm run doctor
```

`npm ci` installs from the lockfile, which is authoritative. Node is pinned in
`.nvmrc` and `engines`. `npm run doctor` reports whether this machine can run
the whole workflow and names the fix for anything missing, including the
optional tools no gate needs.

## A film is three tracked files

```
work/<brand>/<slug>/
  film.json     duration, the beat table, images, narration, budget
  beats.html    one <template> per beat, plus the master timeline
  NOTES.md      intent, assets and licences, the beat prose
```

Those three, and nothing else, are tracked per film. Everything a HyperFrames
project needs is generated by `npm run pre` and gitignored: `index.html`,
`compositions/*.html`, `brand.css`, `gsap.min.js`, `media/`, `captions.vtt`,
`prepared.json`. Never edit a generated file; edit the three above and re-run.
`npm run clean` removes every generated path, `npm run pre` restores them byte
for byte.

Shared sources live in `brands/<slug>/` (pack, faces, shapes, shared scenes),
`media/<brand>/` (captures and traced artwork) and `lib/` (world template,
composition template, player). A film change never edits `lib/` or `tools/`.

| | |

Run those full invocations. Do not consult a tool reference to reconstruct one.

## film.json

`beats[]` is the retime table. A beat is `{id, layer, duration, surface}` plus
optional `start`, `scene`, `vars`. `start` is derived: a beat begins where the
last one ended unless it pins its own, and a pinned beat still advances the
cursor. `layer` is art, type, ui or grade. `surface` is required: `"default"`
or a `.s-<name>` the pack declares. `scene` points a beat at a shared scene
instead of a local template. Track indexes and one timeline label per beat are
derived, so a retime is one number here and nothing else moves.

Also: `labels` for extra timeline labels, `images` naming files in
`media/<brand>/`, `vo` for the narration that generates `captions.vtt`,
`motion` for the assertions tier 3 materializes, `chrome` for the player's
poster, captions and audio flags, and `budget` (see Determinism).

## beats.html

```
<template data-film>          the film's own <style> and the master <script>
<template data-layer="type">  markup into that layer, beside its hosts
<template data-beat="quiz">   one beat: <style>, markup, <script>
```

A beat's script builds `t`; the generator assigns it to `window.__timelines`.
The master script already has `tl`, every label, and a clamped
`camera(scale, x, y)`.

`<!--include name-->` inlines `media/<brand>/name.svg` or
`brands/<brand>/gfx/name.html`. That is how traced artwork and token-bound
shapes reach a beat without living in a file a person edits. Images are
`var(--img-<name>)`, never a `url()`. In a layer template `<!--hosts-->` marks
where that layer's beat hosts go; leave it out and they go last, painting over
the layer's own markup.

## HyperFrames composition rules

Root: `<div id="root" data-composition-id data-width data-height
data-duration>`. Root duration is read once at compile time and is the
lockfield; a clip's duration is re-read live.

Timing attributes: `data-start`, `data-duration`, `data-track-index`.
`data-end` and `data-layer` are derived or legacy; never author them. Media:
`data-src`, `data-media-start`, `data-playback-rate`, `data-volume`,
`data-audio-group`, `data-fx-chain`, `data-automation`; every `<audio>` needs
an `id` or the mixer never sees it and the render is silent. Bindings are
`data-var-text` and `data-var-src`, grading is `data-color-grading`.

One `gsap.timeline({paused:true})` per composition. There is no playback: every
frame is a fresh seek, and anything not on that timeline does not exist.

Hard bans, all upstream lint errors. No `Math.random(`, `Date.now(`,
`new Date()`, `performance.now(`, `crypto.getRandomValues(`,
`gsap.utils.random(` or the `"random(...)"` string form. No
`requestAnimationFrame`, no `repeat:-1`, no template-literal selectors. No
`.from()` on a CSS transform; use `fromTo` with the initial state inside the
tween. No base64 or `data:` source on `<audio>` or `<video>`. No `../` in an
asset path. Never name anything `.caption-group`: it triggers an unconditional
fetch. Layout reads only through `window.__hyperframes.pretext` and
`fitTextFontSize`.

Limits that force the file shape: 300 lines per generated composition, 3 timed
elements per `data-track-index`, 25 elements before the heavy-overlay warning.
One beat per template, from day one.

Ours, not upstream: four fixed layers, `#art` camera-scaled, `#type`
translate-only, `#ui` immune, `#grade` static. Display type never scales.
`filter` is a budgeted craft cost, not a ban.

Brand tokens are composition variables. `brands/<slug>/brand.ts` declares them
and `tools/prepare.mjs` writes the `<html data-composition-variables>` array
from it, so a film cannot drift from its pack. Every scalar becomes `--{id}` on
the root; read it as `var(--ink)`. Eases and anything the build computes with
travel as JS instead: there is no variable type for a curve.

## A beat states the surface it sits on. Always.

`surface: "default"` uses the pack default, so a beat that visually sits on a
dark host renders dark ink on dark and vanishes. The contrast audit does not
catch it: it resolves the ground from the beat's own declaration and never sees
what the host paints behind it. Look at a frame.

## The two gates are different programs

Gate 1 (`check`) validates the generated project. Gate 2 validates the shipped
bytes. Everything the packager adds after gate 1, the typefaces, the player,
the CSP and the attribution, is covered only by gate 2.

Never point `hyperframes check` at a file in `builds/`. The vendored runtime
trips three lint rules, so lint fails, the browser never boots, and every audit
then reports clean and zero. Both gates assert on counts, never on `ok` flags:
there are at least four ways to get a passing verdict on a run that never
happened, and every one reports `ok: true` next to a zero.

## Determinism

Two independent builds must be byte-identical, and a clean checkout must
produce the same bytes as a working tree. Nothing in a build may depend on
wall-clock time, a random source, filesystem order, or an environment variable.
`HYPERFRAME_RUNTIME_URL` must stay unset: it overrides inline packaging and
silently ships a CDN-dependent artifact.

Each film declares what it may weigh in `film.json`:

```json
"budget": { "brotli": 552960, "gzip": 593920, "dclMs": 2200 }
```

The studio defaults are 200 KB brotli, 230 KB gzip and 1500 ms to parse at 4x
CPU throttle. A film only declares a budget when it genuinely carries more, and
gate 2 fails a declared budget that the artifact does not need. One film's
weight never raises another film's allowance.

## Visual review

A gate sees that a film is broken, never that it is wrong. Before calling a
film done, open it and look at the frames a gate cannot judge: the first frame
a viewer sees, every beat boundary, and any beat whose surface differs from the
one behind it. A green gate on an unwatched film is not a finished film.

## House rules, enforced by `npm run guard`

- No em dash character and no encoded em dash entity in any tracked text file.
  Use a comma, a colon or a full stop.
- Nothing generated, cached, snapshotted, copied or temporary is ever tracked.
- No absolute machine path, machine-specific state, secret or personal
  configuration in a tracked file.
- Comments explain a reason that is not obvious from the code. No comment
  walls, no restating what the line does.
- No filler documentation, placeholder file, duplicate configuration, dead code
  or prose that reads as generated.
- No new dependency, abstraction, test framework or test unless it protects
  behaviour that would otherwise break silently. There is exactly one
  `package.json` and every version is pinned exactly.
- Never weaken a check to make a failure disappear. Fix the cause, or state the
  new limit where it is reviewable.

## Git

Do not commit unless you are asked to. Never force push, never rewrite history,
never `git checkout --` or `git reset --hard` over work you did not write, and
never `git add -A` without reading `git status --short` first. Untracked
directories belong to whoever left them there.

Do not run `hyperframes init` anywhere in this repo. It writes per-film routing
files and a per-film `package.json` that forks the single pinned CLI version.

TWO RULES ABOUT CROSSING, both learned from frames: A beat NEVER overlaps the one after it. An overlapped beat paints its opaque world over the outgoing beat's type, which is a text_occluded error at the seam. Instead each beat fades its own page content out over its last quarter second and the next fades its own in, so the shell reads as continuous and only the content area changes. Inside a beat, one screen replaces another on a SET, never on a fade. Two different pages at half opacity is a double exposure: every line of one page reads through the other. Where the page underneath is genuinely the same and only a dialog is new, the set is invisible and the dialog itself is what fades in, which is what the product does. -->
